# Benchmarks manuels d’authentification

Les programmes de ce dossier mesurent Argon2 seul ou le parcours HTTP de connexion avec une base PostgreSQL jetable. Ils restent hors de `src/main` et de la suite de tests habituelle.

Consulter le [mode d’emploi, les comptes fictifs et les résultats de référence](../../docs/benchmarks/authentication/README.md) avant de lancer `Run-AuthenticationBenchmark.ps1`.
